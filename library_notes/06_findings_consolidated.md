## Things confirmed correct (worth protecting with tests)

- **DAMH second-stage acceptance** `log α = Δlog L − Δlog L̃` at `algorithms.py:461-462` is the right
  formula for a π̃-reversible sub-chain kernel; the commented-out "intended" line would add a
  spurious prior ratio. The comment calling it a "weird hot fix" should become a derivation.
- The classic DAMH-SMU pitfall (stale surrogate value at the current state after an update) **is**
  handled (`algorithms.py:345-350`).
- pCN step and prior cancellation are exact for the internal N(0, I) prior; the `transform`
  design needs no Jacobian because `logpdf` lives in internal space.
- HMC: momentum ~ N(0, M), kinetic term ½pᵀM⁻¹p, gradient signs, palindromic leapfrog, momentum
  flip. `HamiltonianInfinite`'s rotation is volume-preserving and reversible (valid for any prior),
  but is prior-preserving only for prior covariance I with mass `diag(sd²)` — document this.
- Surrogate-gradient HMC with exact-likelihood acceptance is a valid MH scheme.
- Evaluator handshake C1–C4 (`communication.py`) is consistent, thanks to the implicit invariant
  "the collector consumes an update signal only when it simultaneously sends an evaluator".
  Document it; moving that call breaks shutdown.
- Barrier accounting: 3 `COMM_WORLD.Barrier` per rank in `run` + 1 in `write_report`, matched.
- Writer ↔ reader formats for `samples/`, `raw_data/`, `notes/`, `subchain_stats/`, both
  surrogate-quality CSVs match (note 04).
- Evaluator pickling ships weights only, on CPU, in `eval()` mode.
- Deletion of `torch_perceptron_outnorm.py` leaves no dangling references.
