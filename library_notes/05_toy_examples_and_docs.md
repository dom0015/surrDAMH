## Packaging and repo hygiene
- `setup.py:41` `python_requires='>=3'` is far too permissive: the codebase uses PEP 604 `X | None` unions pervasively (`configuration.py`, `stages.py`, `solvers.py`, `solver_specification.py` companions, all surrogate/distribution modules) which require **Python ≥ 3.10**, and CLAUDE.md states the project targets **Python 3.12**. `python_requires` should read at least `>=3.10`, ideally `>=3.12` to match CLAUDE.md.
- `setup.py` `install_requires` is missing `torch`, `scikit-learn`, `emcee` (present in `requirements.txt` but not `setup.py`) — see Documentation section above; this is the same issue the task brief called out by name.
